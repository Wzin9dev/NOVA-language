# Contribuindo para a NOVA

Obrigado pelo interesse em contribuir! Este projeto está em fase de especificação, então toda colaboração é bem-vinda.

## Como contribuir

1. Faça um fork do repositório.
2. Crie uma branch para sua mudança: `git checkout -b minha-contribuicao`
3. Commit suas alterações: `git commit -m "Descrição clara da mudança"`
4. Push para o seu fork: `git push origin minha-contribuicao`
5. Abra um Pull Request.

## Onde contribuir

- **Especificação** (`docs/ESPECIFICACAO.md`): correções, melhorias de clareza, novos exemplos.
- **Gramática formal** (`docs/GRAMATICA.md`): discussão sobre a BNF.
- **Extensão VS Code** (`editores/vscode/`): melhoria do highlighting, snippets, tema LSP.
- **Exemplos** (`exemplos/`): novos programas de demonstração.

## Estilo

- Documentos em Português (pt-BR).
- Código de exemplo sempre funcional na sintaxe descrita na especificação.
